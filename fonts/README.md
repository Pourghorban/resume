# Bundled fonts

## Vazirmatn

- **Files:** `Vazirmatn-Regular.ttf`, `Vazirmatn-Medium.ttf`, `Vazirmatn-Bold.ttf`
- **Version:** 33.003
- **Source:** [github.com/rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn)
- **License:** SIL Open Font License 1.1 — full text in [`OFL.txt`](OFL.txt)

Used by `resume-fa.tex` for Persian/Arabic-script text via `xepersian`.

## EB Garamond

Used by `resume-en.tex` but **not bundled** in this repository — it is loaded
from the system font list via `fontspec`. EB Garamond is also distributed
under the SIL Open Font License 1.1. To build `resume-en.tex` locally, install
it yourself, e.g. via TeX Live/MiKTeX (`ebgaramond` package) or as a system
font from [github.com/georgd/EB-Garamond](https://github.com/georgd/EB-Garamond).
